# 🤖 Jarvis – Personal Desktop Voice Assistant

Jarvis is a smart and customizable **desktop voice assistant** built using **Python, Eel, HTML, CSS, and JavaScript**.  
It allows you to control your **PC and Android mobile** using simple **voice or text commands**.

From launching applications to making phone calls and chatting, Jarvis brings **AI-powered automation** right to your fingertips.
