# 🤖 Jarvis – Personal Desktop Voice Assistant

Jarvis is a smart and customizable **desktop voice assistant** built using **Python, Eel, HTML, CSS, and JavaScript**.  
It allows you to control your **PC and Android mobile** using simple **voice or text commands**.

From launching applications to making phone calls and chatting, Jarvis brings **AI-powered automation** right to your fingertips.

---

## ✨ Features

- 🎙️ **Control via Voice & Typing**
- 📞 **Make Phone Calls via Android Mobile**
- 📲 **Pick Up & Disconnect Calls**
- 💻 **Launch Desktop Applications**
- 🌐 **Open Your Favorite Websites**
- 📔 **Built-in Phone Book**
- 🙋 **Store & Use Personal Details**
- 🤖 **Chat Interaction**
- 🎵 **Play Songs & Videos on YouTube / Spotify**
- 🌤️ **Check Real-Time Weather Updates**

---

## 🛠️ Technologies Used

- **Python**
- **Eel (Python ↔ Web Interface)**
- **HTML**
- **CSS**
- **JavaScript**
- **Android (ADB integration)**

---

## 🚀 How It Works

1. User gives a **voice or text command**
2. Python processes the command
3. Eel connects Python with the web UI
4. Required action is performed on **PC or Mobile**
